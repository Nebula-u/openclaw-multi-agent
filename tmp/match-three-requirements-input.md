# 消消乐游戏需求输入

制作一个 Web 端单人本地消消乐游戏，无需后端、登录或联网。第一版采用 8×8 棋盘、6 种方块、相邻交换、三连及以上消除、下落补充、连锁消除、基础计分、步数模式、胜负弹窗、重新开始、响应式布局和 localStorage 最高分。优先保证可玩性与稳定性，特殊方块可作为后续扩展，但核心验收必须完整实现。推荐 HTML/CSS/JavaScript 或 Vite，项目应能在本地浏览器运行。

验收重点：初始棋盘无自动消除且至少有有效步；无效交换回退；有效消除、下落、补充、连锁、计分和步数正确；无可用步时安全洗牌；动画期间禁止重复操作；PC/移动端可操作；刷新后最高分保留；提供启动/游戏/结果界面。
