
OpenClaw 2026.7.1-2 (0790d9f) — All your chats, one OpenClaw.

Usage: openclaw config patch [options]

Patch config from a JSON5 object in one validated write.
Objects merge recursively, arrays/scalars replace, and null deletes a path.
Examples:
openclaw config patch --file ./openclaw.patch.json5 --dry-run
openclaw config patch --stdin

Options:
  --allow-exec           Dry-run only: allow exec SecretRef resolvability checks
                         (may execute provider commands) (default: false)
  --dry-run              Validate changes without writing openclaw.json (checks
                         schema and SecretRef resolvability; exec SecretRefs are
                         skipped unless --allow-exec is set) (default: false)
  --file <path>          Read a JSON5 config patch object from file
  -h, --help             Display help for command
  --json                 Output dry-run result as JSON (default: false)
  --replace-path <path>  Replace the object or array at this dot/bracket path
                         instead of recursively applying it (repeatable)
                         (default: [])
  --stdin                Read a JSON5 config patch object from stdin (default:
                         false)
