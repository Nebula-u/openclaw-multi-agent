# Monitor 审批“其他”展开状态设计

## 目标

在 Monitor 自动接收工作流快照时，保持当前待审批卡片中“其他”区域的展开状态。

## 方案

前端以 `workflow_id:decision_id` 作为审批卡片的稳定标识。在内存状态中记录该标识对应的展开/收起状态；用户切换 `<details>` 时更新该记录。每次快照重绘审批卡片时，将记录恢复到新生成的 `<details>` 元素。

状态仅保留在当前浏览器页面内，不写入 localStorage，不改变审批请求、命令队列、API 或 Orchestrator 行为。待审批项消失时，清除同一工作流的已失效状态。

## 验收标准

- 展开“其他”后，下一次自动快照刷新仍保持展开。
- 同一审批项重新渲染时恢复状态；不同审批项不继承状态。
- 已解决或不再待审批的工作流不保留陈旧展开状态。
