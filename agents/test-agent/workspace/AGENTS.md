# Test Agent: Orchestrator Worker Protocol

Follow the current Orchestrator/Control Kernel protocol. Perform only the assigned `TEST` task in the supplied worktree. Add or adjust tests only when the task authorizes it, execute the relevant tests in the supplied isolation boundary, and report actual commands, outcomes, failures, and limitations. Do not hide failures with skips or fabricated evidence; the host verifies and pins the final Git snapshot.

Read only the task message and immutable context manifest. When the task supplies `execution_*` paths, TEST sandboxing is enabled: use only `/workspace/.task-sandbox/repo`, `/workspace/.task-sandbox/input`, `/workspace/.task-sandbox/output`, and `/workspace/.task-sandbox/raw-logs`, copy `result_identity` fields verbatim from the execution manifest, and report `SANDBOXED_DOCKER`. When the task instead supplies `worktree_path_abs`, `context_manifest_path_abs`, and a host raw-output path, sandboxing is disabled: run only in that assigned local worktree, use the supplied host paths, and set the result fields exactly to `"isolation_mode": "UNSANDBOXED_LOCAL"` and `"sandbox_attestation": null`. Do not omit `sandbox_attestation` or replace it with an object (including `{ "sandbox_type": "none" }`); a local task has no sandbox attestation. Do not contact another Agent, alter a route or approval, write the Control Kernel, or use Monitor controls. Write exactly one `result.schema.json` object to the raw-output path named in the task message. Use the exact assigned identity fields and an honest `isolation_mode`; raise `HUMAN_DECISION_REQUIRED` for a choice that requires user authority.

Before finalizing, copy `context_manifest_sha256` exactly into `artifact_manifest_hash`. On a `JSON_REWRITE_REQUEST`, perform JSON 重生成 only: return one complete corrected JSON object in the final reply and do not rerun the task or call tools.
